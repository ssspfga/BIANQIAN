# 便签（Windows + Android 同一套界面）

极简便签应用，界面只有一份 `www/index.html`：Windows 用 Electron 跑，安卓用 Capacitor 打包，两端界面、数据格式完全一致，通过 WebDAV 同步。

## 界面说明

```
┌──────────────────────────────────────┐
│  ⚙ 设置       便  签  本地       🗑 │
│ ┌──────────────────────────────────┐ │
│ │ (+) 新建便签…（回车保存）         │ │
│ └──────────────────────────────────┘ │
│  ◐ 周五对方案                    📌 │
│     │ ✓ 带报价单                    │
│     │ ○ 带会议记录                  │
│     · 1/2 子项 · 08:06               │
│  ○ 买牛奶、鸡蛋                      │
└──────────────────────────────────────┘
```

### 新建 / 子项

- **最上面一行**：写内容按回车（或点 `+`）就新建一条便签。
- **点便签文字**进入编辑，**回车 = 在这条便签下面新增一个子项**，`Shift+回车` 才是换行，`Esc` 取消。
- 子项里**回车** = 继续新增下一个子项；子项文字清空 / 空行按 `Backspace` = 删掉这个子项。

### 打钩与回收站

- 每条便签左边是**大勾**，每个子项左边是**小勾**。
- 子项勾完（**全部勾上**）→ 整条便签自动移到回收站；勾到一半时大勾显示成「横线」状态。
- 直接点**大勾** → 不管子项状态，整条（含子项）立刻进回收站。
- 右上角 🗑 是回收站（不显示条数，点进去看）。
- 回收站里**点左边的勾取消打钩** → 这条便签回到列表，并且**重置为未完成状态**（子项全部清空勾选）；右边「删除」是彻底删除，右上角图标清空回收站。

### 置顶（打钉）

每条便签右边有个图钉，点亮后这条固定在列表最前面（Windows 和安卓都可以用）。

### 电脑端窗口（Windows）

窗口是无边框的，顶部有一条拖动栏：

- 左上角图钉 = **窗口置顶**（始终浮在最前面，状态保存在本机）；
- 图钉右边那个按钮 = **立即贴边收起**（手动收起，不用拖到边缘）；
- 右上角是**最小化 / 关闭**；
- **贴边收起**：把窗口拖到屏幕左边缘或右边缘，鼠标移开约 0.7 秒后会自动滑进屏幕外，只留一条细蓝条；**鼠标碰到那条细条（或点一下）就会滑出来**，点任务栏图标也能唤出；
- **窗口置顶默认开着**：每次启动都直接浮在最前面，点图钉可临时取消；
- **开机自动启动默认开着**：第一次运行就会把本程序登记到登录启动项（HKCU\Software\Microsoft\Windows\CurrentVersion\Run），想关在设置里关掉即可；换了 exe 的存放位置后，把开关关一次再打开就会重新登记；
- 收起后在屏幕上只剩一条 **10px 宽、高度为原窗口 1/5** 的蓝色小条（垂直居中在原位置），鼠标碰到或点一下整窗滑出；
- 这些开关都在设置页「窗口（电脑端）」里，可以随时关掉。

## 一、Windows 上运行

### 直接用打好的包

`dist\便签 1.0.0.exe` 是免安装单文件版（约 68 MB），双击就能跑，不需要装 Node。

### 从源码跑 / 重新打包

需要 Node.js 18+：

```powershell
cd D:\3D对象\智能体\便签工具
npm install
npm start
```

打包免安装 exe：

```powershell
npm run win
```

产物在 `dist/`。桌面端走主进程发 HTTP 请求，WebDAV 没有跨域问题；导出文件会弹系统保存框。

> 本机目前没装 Node，打包时用的是临时便携版 Node（`%LOCALAPPDATA%\Temp\node-portable\node-v22.16.0-win-x64`）+ npmmirror 镜像，命令见对话记录。

## 二、安卓打包（GitHub 上跑）

仓库已带 `.github/workflows/android.yml`，推到 GitHub 后：

1. Actions 自动跑，也可手动 `Run workflow`；
2. 跑完在 Artifacts 里下载 `biji-debug-apk`；
3. 装到手机上（允许「安装未知来源应用」）。

本地打也可以：

```powershell
npm install
npx cap add android
npx cap sync android
npx cap open android
```

改应用名 / 包名：改 `capacitor.config.json` 里的 `appName`、`appId`（在第一次 `cap add android` 之前改）。

## 三、WebDAV 同步

左上角 ⚙ 设置里填：

| 字段 | 例子 |
| --- | --- |
| 服务器地址 | `https://dav.jianguoyun.com/dav/` |
| 账号 | 坚果云登录邮箱 |
| 应用密码 | 坚果云「账户信息 → 安全选项 → 添加应用密码」生成的密码（**不是**登录密码） |
| 同步目录 | `便签`（先在网盘里建好这个文件夹；留空表示根目录） |
| 文件名 | `便签.json` |

Nextcloud / 群晖 / InfiniCLOUD 等填各自的 WebDAV 根地址即可。

**同步策略**

- 启动时、手动点「同步」、以及改动后 2.5 秒自动同步（正在编辑时会等你编辑完）；
- 拉下来按「三路合并」处理：只有一边改过 → 自动采用改过的那边；两边都改了同一条 → **判定为冲突**，弹面板让你选「本地版本 / 云端版本」；
- 彻底删除会留 90 天墓碑，防止另一台设备把它同步回来；
- 底部状态栏显示「已同步 10:32」或失败原因（401 密码错、409 目录不存在等都有中文提示）。

### 冲突时怎么处理

同步撞车时会弹「同步冲突」面板，每条冲突并排显示本地版和云端版（含子项和打钩状态），你可以：

- 点某一边 = 这条用那个版本（默认选中较新的那份）；
- **全部用本地** / **全部用云端** 一键决定；
- **导出两个文件** → 分别导出 `便签-本地-时间.json` 和 `便签-云端-时间.json`，自己留着对比；Windows 弹保存框，安卓存到手机「文档」目录；
- **完成并同步** → 按你的选择合并后上传。

只要你不动，冲突不会覆盖任何一边的数据。

## 四、本地备份

两端都会在本机留一份备份，设置页最下面有「本地备份」区域：

- 应用启动、每次云端合并前会自动留一份快照（本机保留最近 3 份）；
- Windows 另外会把备份写成真实文件，放在用户数据目录的 `backups` 文件夹（设置里可一键打开），保留最近 20 份；
- 「立即备份」手动存一份；「导出备份文件」导出完整 JSON；「从备份恢复」用最近快照覆盖当前数据（覆盖前会先自动备份当前状态）。

## 五、文件结构

```
便签工具/
├─ www/index.html              ← 唯一界面（Windows/安卓共用）
├─ electron/main.js            ← Windows 外壳：WebDAV 请求、保存对话框、本地备份
├─ electron/preload.js
├─ capacitor.config.json       ← 安卓打包配置
├─ package.json
├─ .github/workflows/android.yml
└─ README.md
```

本地数据：`localStorage` 键 `notes.data.v1`（便签）、`notes.cfg.v1`（WebDAV 配置，含密码，只在本机）、`notes.base.v1`（上次同步基线，用来判断冲突）、`notes.backup.v1`（本地快照）。

数据结构：每条便签 `{ id, text, pinned, createdAt, updatedAt, children:[{ id, text, done, updatedAt }] }`，进回收站时多一个 `deletedAt`。
