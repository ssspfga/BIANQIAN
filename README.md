# 便签（Windows + Android 同一套界面）

极简便签应用，界面只有一份 `www/index.html`：Windows 用 Electron 跑，安卓用 Capacitor 打包，两端界面、数据格式完全一致，通过 WebDAV 同步。

## 界面说明

```
┌──────────────────────────────────────┐
│  ⚙ 设置       便  签  本地       🗑 │
│ ┌──────────────────────────────────┐ │
│ │ (+) 新建便签…（回车保存）         │ │
│ └──────────────────────────────────┘ │
│  ◐ 周五对方案                    📌 │
│     │ ✓ 带报价单                    │
│     │ ○ 带会议记录                  │
│     · 1/2 子项 · 08:06               │
│  ○ 买牛奶、鸡蛋                      │
└──────────────────────────────────────┘
```

### 新建 / 子项

- **最上面一行**：写内容按回车（或点 `+`）就新建一条便签。
- **点便签文字**进入编辑，**回车 = 在这条便签下面新增一个子项**，`Shift+回车` 才是换行，`Esc` 取消。
- 子项里**回车** = 继续新增下一个子项；子项文字清空 / 空行按 `Backspace` = 删掉这个子项。

### 打钩与回收站

- 每条便签左边是**大勾**，每个子项左边是**小勾**。
- 子项勾完（**全部勾上**）→ 整条便签自动移到回收站；勾到一半时大勾显示成「横线」状态。
- 直接点**大勾** → 不管子项状态，整条（含子项）立刻进回收站。
- 右上角 🗑 是回收站（不显示条数，点进去看）。
- 回收站里**点左边的勾取消打钩** → 这条便签回到列表，并且**重置为未完成状态**（子项全部清空勾选）；右边「删除」是彻底删除，右上角图标清空回收站。

### 置顶（打钉）

每条便签右边有个图钉，点亮后这条固定在列表最前面（Windows 和安卓都可以用）。

### 标签与竖向筛选

- 每条便签右边、图钉左边有个**标签按钮**：点开可以勾选已有标签，也能在下面输入框新建（比如「客户」「当前待办」）。
- 卡片最右边有一条**竖向筛选栏**：最上面固定是「全部」，下面按标签的使用次数排下来，几个标签就均分成几格。
  - **短按**某个标签 = 只看这个标签的便签
  - **长按**另一个标签 = 叠加（只看同时属于这几个标签的，比如「客户」+「当前待办」）
  - 再短按一次已选中的标签 = 取消筛选，回到全部
- 筛选栏最下面有个**箭头**，点一下把整条筛选栏换到左边/右边（位置会记住）。
### 标签清单存在哪里

- **随应用打包的**：www/标签.txt（一行一个标签），第一次运行时读进来当初始清单
- **云端**：同步目录下的 标签.txt，电脑和手机共用同一份；也可以直接在坚果云里编辑这个文件改清单
  （同步规则：本地改过标签 → 推上去；本地没改过 → 以云端为准）
- 在标签面板里点 chip 右边的 **×** 就能删掉一个标签，所有便签会同时去掉它
### 电脑端窗口（Windows）

窗口是无边框的，顶部有一条拖动栏：

- 左上角图钉 = **窗口置顶**（始终浮在最前面，状态保存在本机）；
- 图钉右边那个按钮 = **立即贴边收起**（手动收起，不用拖到边缘）；
- 右上角是**最小化 / 关闭**；
- **贴边收起**：把窗口拖到屏幕左边缘或右边缘，鼠标移开约 0.7 秒后会自动滑进屏幕外，只留一条细蓝条；**鼠标碰到那条细条（或点一下）就会滑出来**，点任务栏图标也能唤出；
- **窗口置顶默认开着**：每次启动都直接浮在最前面，点图钉可临时取消；
- **开机自动启动默认开着**：第一次运行就会把本程序登记到登录启动项（HKCU\Software\Microsoft\Windows\CurrentVersion\Run），想关在设置里关掉即可；换了 exe 的存放位置后，把开关关一次再打开就会重新登记；
- 收起后在屏幕上只剩一条 **10px 宽、高度为原窗口 1/5** 的蓝色小条（垂直居中在原位置），鼠标碰到或点一下整窗滑出；
- 这些开关都在设置页「窗口（电脑端）」里，可以随时关掉。

## 一、Windows 上运行

### 直接用打好的包

`dist\便签 1.0.0.exe` 是免安装单文件版（约 68 MB），双击就能跑，不需要装 Node。

### 从源码跑 / 重新打包

需要 Node.js 18+：

```powershell
cd D:\3D对象\智能体\便签工具
npm install
npm start
```

打包免安装 exe：

```powershell
npm run win
```

产物在 `dist/`。桌面端走主进程发 HTTP 请求，WebDAV 没有跨域问题；导出文件会弹系统保存框。

> 本机目前没装 Node，打包时用的是临时便携版 Node（`%LOCALAPPDATA%\Temp\node-portable\node-v22.16.0-win-x64`）+ npmmirror 镜像，命令见对话记录。

## 二、安卓打包（GitHub 上跑）

仓库已带 `.github/workflows/android.yml`，推到 GitHub 后：

1. Actions 自动跑，也可手动 `Run workflow`；
2. 跑完在 Artifacts 里下载 `biji-debug-apk`；
3. 装到手机上（允许「安装未知来源应用」）。

本地打也可以：

```powershell
npm install
npx cap add android
npx cap sync android
npx cap open android
```

改应用名 / 包名：改 `capacitor.config.json` 里的 `appName`、`appId`（在第一次 `cap add android` 之前改）。

### 固定签名（能覆盖安装的前提）

仓库里带了一个 `signing.gradle`，配合 GitHub Secret `KEYSTORE_BASE64` 使用：

1. 用自己的 keytool 生成一个 keystore，转成 base64（一行文本）
2. 仓库 → Settings → Secrets and variables → Actions → 新建 Secret：名字 `KEYSTORE_BASE64`，值粘那行 base64
3. 之后每次构建：workflow 解码出 `android/app/biji.keystore` → 套用固定签名 → `versionCode` 用运行序号递增

这样每次出的 APK 签名都一样，**新包可以直接覆盖安装，不用卸载，数据也保留**。
没配这个 Secret 也能正常出包，只是签名每次都变，装不上旧版。
keystore 千万别提交到仓库（`.gitignore` 已排除 `*.keystore`）。


## 三、WebDAV 同步（云端为准 + 明文 CSV）

左上角 ⚙ 设置里填：

| 字段 | 例子 |
| --- | --- |
| 服务器地址 | `https://dav.jianguoyun.com/dav/` |
| 账号 | 坚果云登录邮箱 |
| 应用密码 | 坚果云「账户信息 → 安全选项 → 添加应用密码」生成的密码（**不是**登录密码） |
| 同步目录 | `便签`（先在网盘里建好这个文件夹；留空表示根目录） |

不需要填文件名。同步目录下会自动生成两个**明文 CSV**，随时可以用 Excel 打开看：

| 文件 | 内容 |
| --- | --- |
| `便签.csv` | 所有**未完成**的便签（含子项） |
| `已办.csv` | 所有**已勾选完成 / 已进回收站**的便签（含"已彻底删除"的少量墓碑行） |

CSV 列：`Id, 父Id, 排序, 内容, 状态, 已完成, 置顶, 创建时间, 更新时间, 删除时间, 标签`（标签用竖线 `|` 分隔，标签名里别写 `|`）
（便签行的父Id为空；子项行的父Id是所属便签的 Id；状态取值 `正常 / 已办 / 已删`。文件带 UTF-8 BOM，Excel 直接打开中文不乱码。）

**同步规则（以云端为准）**

- 启动时、手动点「同步」、以及改动后 2.5 秒自动同步（正在编辑时等编辑完再传）；
- **云端有这条 → 用云端的；云端没有 → 用本地的并上传**；
- 细分一下：本地没改过 → 直接用云端；云端没改过 → 用本地的（你的修改会传上去）；**两边都改过 → 以云端为准**（状态栏会提示"N 条冲突按云端为准"）；
- 覆盖本地之前，会先把当前本地数据存一份备份（设置 → 本地备份里能找回）；
- 彻底删除留 90 天墓碑，防止另一台设备把它同步回来；
- 旧版本留下的 `便签.json` 会自动被读取并转换成上面两个 CSV；转换后那个 JSON 不会删，留着当备份，你可以自己删掉。

## 四、本地备份

两端都会在本机留一份备份，设置页最下面有「本地备份」区域：

- 应用启动、每次云端覆盖前会自动留一份快照（本机保留最近 3 份）；
- Windows 另外会把备份写成**明文 CSV**（`便签-时间.csv` / `已办-时间.csv`），放在用户数据目录的 `backups` 文件夹（设置里可一键打开），保留最近 20 份；
- 「立即备份」手动存一份；「导出备份文件」导出这两个 CSV；「从备份恢复」用最近快照覆盖当前数据（覆盖前会先自动备份当前状态）。
## 五、文件结构

```
便签工具/
├─ www/index.html              ← 唯一界面（Windows/安卓共用）
├─ electron/main.js            ← Windows 外壳：WebDAV 请求、保存对话框、本地备份
├─ electron/preload.js
├─ capacitor.config.json       ← 安卓打包配置
├─ package.json
├─ .github/workflows/android.yml
└─ README.md
```

本地数据：`localStorage` 键 `notes.data.v1`（便签）、`notes.cfg.v1`（WebDAV 配置，含密码，只在本机）、`notes.base.v1`（上次同步基线，用来判断"谁改过"）、`notes.backup.v1`（本地快照）。云端存的是明文 CSV。

数据结构：每条便签 `{ id, text, pinned, createdAt, updatedAt, children:[{ id, text, done, updatedAt }] }`，进回收站时多一个 `deletedAt`。
